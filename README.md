# WP Cursor

Plugin WordPress : composants PHP versionnés, shortcodes Divi, admin de prévisualisation.

## Structure

- `components/` — blocs réutilisables (PHP, CSS, JSON)
- `includes/` — admin, shortcodes, REST, Divi
- `assets/` — JS/CSS admin

## Installation

Copier le dossier dans `wp-content/plugins/wpcursor/` et activer **WP Cursor** dans WordPress.

## Développement

Les modifications peuvent être faites via l’admin WordPress ou via **Cursor Cloud Agents** sur ce dépôt.
